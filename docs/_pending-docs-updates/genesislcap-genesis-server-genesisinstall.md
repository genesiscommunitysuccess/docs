## `genesisInstall`

The `genesisInstall` command installs and configures the Genesis application. It processes configuration files, GPAL scripts, and system definitions to prepare the runtime environment.

###### Blocking execution in containerised environments
To prevent accidental execution of `genesisInstall` in containerised environments (such as Docker), you can block this command using the `BlockGenesisInstall` system definition property.

When `BlockGenesisInstall` is set to `true`, running `genesisInstall` prints a warning and exits cleanly without performing any installation steps. This is the default behaviour in Docker images generated by the Genesis Gradle plugin, where configuration and GPAL changes should be applied by rebuilding and redeploying the image.

You can configure this behaviour in your system definition file `genesis-system-definition.kts` or override it using an environment variable.

###### Syntax
| Argument | Mandatory | Description | Restricted values | Default |
|---|---|---|---|---|
| none | no | Runs the installation process | none | none |

###### Examples

To run the installation process normally:
```bash
genesisInstall
```

To override the block and allow `genesisInstall` to run inside a container, you can set the environment variable before running the command:
```bash
export GENESIS_SYSDEF_BlockGenesisInstall=false
genesisInstall
```
