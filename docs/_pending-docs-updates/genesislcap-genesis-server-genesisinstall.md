## `genesisInstall`

The `genesisInstall` command installs and configures the Genesis Application Platform and your application's database schema. It must be run during the initial setup of your application and after any schema changes.

### Blocking `genesisInstall` in containerised environments

To prevent accidental execution of `genesisInstall` in containerised environments (where configuration and schema changes must be managed via image rebuilds and redeployments), you can block this command using the `BlockGenesisInstall` system definition property.

By default, Docker runtime images generated by the Genesis Gradle plugin set the environment variable `GENESIS_SYSDEF_BlockGenesisInstall=true`.

When `BlockGenesisInstall` is set to `true`:
- Running `genesisInstall` prints a warning and exits cleanly without performing any changes.
- To apply system definition updates in these environments, you must use environment variables.
- For configuration or GPAL changes, you must build and redeploy a new container image.

###### Examples

To temporarily bypass this block and run `genesisInstall` inside a container (for example, during troubleshooting), set the environment variable to `false` before running the command:

```bash
export GENESIS_SYSDEF_BlockGenesisInstall=false
genesisInstall
```
