### Breaking changes

* V9 alignment — Gradle 9.6.1 + javax.inject→jakarta.inject
* Migrate the SharePoint storage manager to Graph SDK v6

### Features

* `codegen` : Enable reuseUpstream codegen, opt test dict-cache out
* `file-server` : File-expiry retention for Document Manager
* Add ability to provide project id to gcs
* Implement google cloud file storage manager
* Make GCS userProject optional

### Fixes

* `build` : Keep genesis dev tools out of the ktlint codegen dependencies
* `file-server` : Compile against Jackson 3
* `file-server` : Stop importing Kotlin compiler internals
* FileType used in FileStorageClient must be available in API library
* Save Document API should allow file type to be provided
* Adapt file-server to GSF websocket/HTTP DSL refactor
* Adapt to genesis-db classForName move and pipeline DSL build() change
* Bump seed-utils to 15.6.2 to unblock FoundationUI 15 apps
* Cap test retries with maxFailures to stop amplification
* Delete test temp dirs without the Artemis FileUtil
* Deleting a file should unlink the templates and assets
* File separator issue when appending to file name
* Load and delete should use folder prefix
* Migrate javax.annotation imports to jakarta
* Resolve version from the first @genesislcap/* dependency
* Update RequestType import after genesis-net websocket refactor
