### Features

* feat(notifications): include DYNAMIC_RULE_ID on screen alerts from notification rules
* feat(notify): return broadcastTopics and skip Exclude Sender on SELF
* feat: Add Slack as a Notify gateway
* feat: Add a shared gateway for Slack and Teams to base their integration off
* feat: Allow asset references to be passed to email notify api
* feat: Enable slice jar publishing and fix reuseUpstream scoping
* feat: persist and serve custom alert sounds for notification rules and templates
* feat: support custom SMTP headers on email gateway

### Fixes

* fix(genesis-notify-dispatcher): build the webhook mapper on Jackson 3
* fix(genesis-notify-script-config): change deprecated dsl syntax
* fix(notify): default RouteCreate.displayName to null
* fix(notify): scope SELF routes by entityId so per-user subscriptions don't cross-deliver
* fix: Email API should allow optional template reference parameter
* fix: Ensure bulk dismiss is batched to avoid overwhelming the process memory
* fix: allow alert sound fetch for service-owned notification rules
* fix: bump seed-utils to 15.6.2 to unblock FoundationUI 15 apps
* fix: cap test-retry failures and add noRetry guard
* fix: exclude genesis-notify-test-dictionary-cache from product manifest
* fix: remove unused context parameter from register function
* fix: resolve version from the first @genesislcap/* dependency
