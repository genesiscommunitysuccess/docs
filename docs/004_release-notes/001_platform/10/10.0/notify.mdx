### Features

* `notifications` : Include DYNAMIC_RULE_ID on screen alerts from notification rules
* `notify` : Return broadcastTopics and skip Exclude Sender on SELF
* Add Slack as a Notify gateway
* Add a shared gateway for Slack and Teams to base their integration off
* Allow asset references to be passed to email notify api
* Enable slice jar publishing and fix reuseUpstream scoping
* Persist and serve custom alert sounds for notification rules and templates
* Support custom SMTP headers on email gateway

### Fixes

* `genesis-notify-dispatcher` : Build the webhook mapper on Jackson 3
* `genesis-notify-script-config` : Change deprecated dsl syntax
* `notify` : Default RouteCreate.displayName to null
* `notify` : Scope SELF routes by entityId so per-user subscriptions don't cross-deliver
* Email API should allow optional template reference parameter
* Ensure bulk dismiss is batched to avoid overwhelming the process memory
* Allow alert sound fetch for service-owned notification rules
* Bump seed-utils to 15.6.2 to unblock FoundationUI 15 apps
* Cap test-retry failures and add noRetry guard
* Exclude genesis-notify-test-dictionary-cache from product manifest
* Remove unused context parameter from register function
* Resolve version from the first @genesislcap/* dependency
