### Breaking changes

* V9 alignment — Gradle 9.6.1 + javax.inject→jakarta.inject
* Migrate quickfixj-core from 2.3.2 to 3.0.2
* Remove fix-webextension ahead of the genesis-webmon removal

### Features

* `codegen` : Enable slice jar publishing and fix reuseUpstream scoping
* Add Dependabot auto-merge workflow
* Upgrade kotlin to version 2.3.10
* Revert Add Dependabot auto-merge workflow

### Fixes

* `fix-config` : Parse FixAdmin.groovy arguments without CliBuilder
* `fix-distribution` : Opt in to publishing the genesis manifest
* `fix-eventhandler` : Restore target sequence number from the latest FIX_IN message
* `fix-eventhandler` : Stop the FIX activity publisher when the process shuts down
* `fix-pipelines` : Don't throw uncaught when target pipeline isn't started
* `fix-shared` : Replace per-record deletion with batched deleteAll in fix session reset with 10000 batch size
* `fix-shared` : Update RandomStringUtil import in FixAdmin.groovy to lang3 to bring import in line with other files
* `server` : Inject Aggregators instead of the removed StreamerClientConfigReader.get()
* Events + Pipelines should nack/throw when session is down
* Cap test-retry maxFailures and add noRetry guard
* Migrate javax.annotation imports to jakarta
* Prevent FixSink from persisting failed sends to the message store
* Stop importing Kotlin compiler internals
