### Breaking changes

* build(deps)!: v9 alignment — Gradle 9.6.1 + javax.inject→jakarta.inject
* feat!: migrate quickfixj-core from 2.3.2 to 3.0.2
* feat!: remove fix-webextension ahead of the genesis-webmon removal

### Features

* feat(codegen): Enable slice jar publishing and fix reuseUpstream scoping
* feat: Add Dependabot auto-merge workflow
* feat: upgrade kotlin to version 2.3.10
* feat: Revert Add Dependabot auto-merge workflow

### Fixes

* fix(fix-config): parse FixAdmin.groovy arguments without CliBuilder
* fix(fix-distribution): opt in to publishing the genesis manifest
* fix(fix-eventhandler): restore target sequence number from the latest FIX_IN message
* fix(fix-eventhandler): stop the FIX activity publisher when the process shuts down
* fix(fix-pipelines): don't throw uncaught when target pipeline isn't started
* fix(fix-shared): Replace per-record deletion with batched deleteAll in fix session reset with 10000 batch size
* fix(fix-shared): Update RandomStringUtil import in FixAdmin.groovy to lang3 to bring import in line with other files
* fix(server): inject Aggregators instead of the removed StreamerClientConfigReader.get()
* fix: Events + Pipelines should nack/throw when session is down
* fix: cap test-retry maxFailures and add noRetry guard
* fix: migrate javax.annotation imports to jakarta
* fix: prevent FixSink from persisting failed sends to the message store
* fix: stop importing Kotlin compiler internals
