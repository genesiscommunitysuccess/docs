### Breaking changes

* Added alternate data grouping strategies to templated reports

### Features

* `codegen` : Enable reuseUpstream codegen
* `reporting` : File-expiry retention for generated reports
* Allow configurable max row limit for request server datasources
* Updated parameterisation implementation with latest design requirements

### Fixes

* `build` : Keep genesis dev tools out of the ktlint codegen dependencies
* `reporting` : Stop importing Kotlin compiler internals for lowercasing
* `reporting-app` : Import UUID from java.util, not JGroups
* Ensure basic excel reports preserve correct type for date and datetime columns
* Ensure reports can be generated using csv templates
* Bump seed-utils to 15.6.2 to unblock FoundationUI 15 apps
* Migrate javax.annotation imports to jakarta
* Resolve version from the first @genesislcap/* dependency
