### Breaking changes

* build(deps)!: v9 alignment — Gradle 9.6.1 + javax.inject→jakarta.inject
* fix(auth-sso-endpoint)!: Implement private_key_JWT authentication for OIDC when SSO is enabled

### Features

* feat(auth): add events to toggle notify-based MFA
* feat(auth): expose notify-based MFA status on ALL_USERS
* feat(auth): support numeric one-time codes for notify-based MFA
* feat(auth-manager): migrate LDAP authentication onto genesis-ldap's engine
* feat(auth-manager): optional per-connection LDAP timeouts and TLS trust/hostname opt-in
* feat: Implement private_key_JWT authentication for OIDC when SSO is enabled
* feat: Rename generated modules and enable slice jar publishing
* feat: add per-IdP tokenDelivery cookie mode for SSO token delivery

### Fixes

* fix(auth): only send a notify MFA code when the user asks for one
* fix(auth): send a new notify MFA code once the last one is used, and send the cooldown to the client
* fix(auth-manager): audit password changes in USER_LOGIN_AUDIT
* fix(auth-manager): expire sessions on a fixed lifetime from START_TIMESTAMP
* fix(auth-manager): mark ONE_TIME_PASSWORD as required in the EVENT_INSERT_USER schema
* fix(auth-manager): raise the hard-coded LDAP timeouts back to 8.15's connect and search defaults
* fix(auth-manager): read product details per LoginProcessor instance
* fix(auth-manager): separate password validation prefix from errors
* fix(auth-messages): point KeyValue byte-array annotations at Jackson 3
* fix(auth-oidc): use lastIndexOf to extract idp from state parameter
* fix(auth-saml): fix typo in standard SAML parameter
* fix(auth-saml): pin SAML Destination validation to configured ACS URL
* fix(auth-script-config): make AUTH-483 audit tests pass on Oracle and MSSQL
* fix: USER_PROFILE_AMEND event fix for right consolidation
* fix: Adapt codebase to new Websocket/HTTP changes in GSF
* fix: Use TLS for user connection if useTls set
* fix: add icons to pbc routes
* fix: bump seed-utils to 15.6.2 to unblock FoundationUI 15 apps
* fix: cap test-retry maxFailures so a broken module stops retrying
* fix: exclude auth-entity-dictionary-cache from product manifest
* fix: migrate javax.annotation imports to jakarta
* fix: migrate the permissioning auth DSL onto authKey
* fix: resolve version from the first @genesislcap/* dependency
* fix: update RequestType import after genesis-net websocket refactor
