### Breaking changes

* V9 alignment — Gradle 9.6.1 + javax.inject→jakarta.inject
* `auth-sso-endpoint` : Implement private_key_JWT authentication for OIDC when SSO is enabled

### Features

* `auth` : Add events to toggle notify-based MFA
* `auth` : Expose notify-based MFA status on ALL_USERS
* `auth` : Support numeric one-time codes for notify-based MFA
* `auth-manager` : Migrate LDAP authentication onto genesis-ldap's engine
* `auth-manager` : Optional per-connection LDAP timeouts and TLS trust/hostname opt-in
* Implement private_key_JWT authentication for OIDC when SSO is enabled
* Rename generated modules and enable slice jar publishing
* Add per-IdP tokenDelivery cookie mode for SSO token delivery

### Fixes

* `auth` : Only send a notify MFA code when the user asks for one
* `auth` : Send a new notify MFA code once the last one is used, and send the cooldown to the client
* `auth-manager` : Audit password changes in USER_LOGIN_AUDIT
* `auth-manager` : Expire sessions on a fixed lifetime from START_TIMESTAMP
* `auth-manager` : Mark ONE_TIME_PASSWORD as required in the EVENT_INSERT_USER schema
* `auth-manager` : Raise the hard-coded LDAP timeouts back to 8.15's connect and search defaults
* `auth-manager` : Read product details per LoginProcessor instance
* `auth-manager` : Separate password validation prefix from errors
* `auth-messages` : Point KeyValue byte-array annotations at Jackson 3
* `auth-oidc` : Use lastIndexOf to extract idp from state parameter
* `auth-saml` : Fix typo in standard SAML parameter
* `auth-saml` : Pin SAML Destination validation to configured ACS URL
* `auth-script-config` : Make AUTH-483 audit tests pass on Oracle and MSSQL
* USER_PROFILE_AMEND event fix for right consolidation
* Adapt codebase to new Websocket/HTTP changes in GSF
* Use TLS for user connection if useTls set
* Add icons to pbc routes
* Bump seed-utils to 15.6.2 to unblock FoundationUI 15 apps
* Cap test-retry maxFailures so a broken module stops retrying
* Exclude auth-entity-dictionary-cache from product manifest
* Migrate javax.annotation imports to jakarta
* Migrate the permissioning auth DSL onto authKey
* Resolve version from the first @genesislcap/* dependency
* Update RequestType import after genesis-net websocket refactor
