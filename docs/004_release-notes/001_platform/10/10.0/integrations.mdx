### Breaking changes

* V9 alignment — Gradle 9.6.1 + javax.inject→jakarta.inject
* `jms-genesis` : Activemq-client 6.3.1 and the jakarta JMS API

### Features

* `cdc-genesis` : Add CDC/Debezium module moved from genesis-server
* `kafka-genesis` : Add an opt-in transactional Kafka sink that fences across a failover
* Added excel decoder library to data pipelines with example

### Performance improvements

* Remove blocking on each send to improve Kafka Sink throughput

### Fixes

* `cdc-genesis` : Exclude the javax JAXB api from where it actually comes from
* `cdc-genesis` : Gate the MsSql CDC test on SQL Server Agent instead of waiting forever
* Bump seed-utils to 15.6.2 to unblock FoundationUI 15 apps
* Migrate javax.annotation imports to jakarta
