# Verification Code Input

Multi-digit numeric input for one-time passwords (OTP), MFA, and other verification codes.

Use cases:
* Multi-factor authentication (MFA) / 2FA
* Email or SMS one-time codes
* Any short numeric verification code

The component is form-associated: `name`, `required`, and `value` participate in native HTML form validation and submission.

Foundation Auth uses this control on the [Verify](/develop/client-capabilities/login/#multi-factor-authentication-mfa) page.

        console.log('change', event.detail.value);
      }

      onComplete(event: CustomEvent<{ value: string }>) {
        console.log('complete', event.detail.value);
      }

      onSubmit(event: Event) {
        event.preventDefault();
        const form = event.target as HTMLFormElement;
        if (!form.reportValidity()) {
          return;
        }
        console.log('submit', this.code);
      }
    }

## Features

* Numeric-only input
* Automatic focus progression between digits
* Arrow Left / Arrow Right navigation
* Backspace and Delete handling
* Paste support with automatic digit distribution
* Form-associated (`FormAssociated`) validation and submission
* First digit uses `autocomplete="one-time-code"` for WebOTP / SMS autofill support

### Methods

| Method | Description |
|---|---|
| `focus()` | Focuses the first digit field |
| `clear()` | Clears the code, emits `change`, and focuses the first digit when connected |

### Slots

| Slot | Use |
|---|---|
| Default | Label content. When empty, the label is visually hidden |

### Parts

| Part | Use |
|---|---|
| label | The label element |
| root | The root wrapper of each digit field |
| control | Each digit `<input>` |
